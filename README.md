# Boidemic

This is a silly proof-of-concept game about leading a flock of boids to steal some poor guy's chips, made to demonstrate Haskell game development using Gloss and Apecs.

All the code is licensed under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (assets *not* included), i.e. you can do whatever you want with it without attribution (although you're welcome to link back to this repo). Feel free to copy any/all of it to start making your next game in Haskell!

## Running the game
- Install GHC and cabal: https://www.haskell.org/ghcup/install/
- Run `cabal run` in the project root

## Controls

- Arrow keys to move
- Esc to quit
